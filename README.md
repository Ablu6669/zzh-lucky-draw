## 📖 简介 / Introduction

**中文：** 一个纯前端的动态抽签系统，内置 18 种炫酷动画效果。用户可自定义抽签内容、抽取数量，并选择心仪的动效。单 HTML 文件，零外部依赖，开箱即用。

## 🛠️ 使用方法 / Usage

### 中文

1. 在输入框中输入抽签内容，**每行一个**
2. 设置要抽取的数量
3. 选择喜欢的动效（或选择「随机动效」）
4. 点击 **开始抽签** 按钮
5. 等待动画播放完毕，查看结果

### English

1. Enter draw entries in the text area, **one per line**
2. Set the number of winners
3. Choose your preferred effect (or select "Random")
4. Click the **Start Draw** button
5. Wait for the animation to finish and see the result

## 🌐 部署到 GitHub Pages / Deploy to GitHub Pages

### 中文

1. Fork 或上传本仓库到 GitHub
2. 进入仓库 **Settings** → **Pages**
3. **Source** 选择 **Deploy from a branch**
4. **Branch** 选择 `main`，文件夹选 `/ (root)`
5. 点击 **Save**，等待 1-2 分钟
6. 访问 `https://<你的用户名>.github.io/<仓库名>/`

### English

1. Fork or upload this repository to GitHub
2. Go to **Settings** → **Pages**
3. Set **Source** to **Deploy from a branch**
4. Select `main` branch and `/ (root)` folder
5. Click **Save**, wait 1-2 minutes
6. Visit `https://<your-username>.github.io/<repo-name>/`
